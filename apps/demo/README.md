# passkey-cloudflare demo

The demo app of the passkey-only identity library in [`packages/passkey-cloudflare`](../../packages/passkey-cloudflare/), live at https://passkeydemo.gordianstack.com: sign-in, settings, adding and revoking passkeys, and recovery codes, over a placeholder app. The forge reuses its sign-in page and styles.

It is a snapshot from [BlockchainCommons/passkey-cloudflare](https://github.com/BlockchainCommons/passkey-cloudflare), where its history and run instructions are.
